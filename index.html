🔍 VERIFY YOUR DOWNLOAD

Always verify checksums before use

Verification Commands

# Linux/macOS
sha256sum nullsec-*.iso

# Windows (PowerShell)
Get-FileHash -Algorithm SHA256 nullsec-*.iso

# Compare with published checksums
cat SHA256SUMS | grep nullsec-pro-3.0-amd64.iso

GPG Signature Verification

# Import NullSec signing key
gpg --keyserver keyserver.ubuntu.com --recv-keys B1F1881F70FB62A7

# Verify signature
gpg --verify nullsec-3.0-amd64.iso.sig nullsec-3.0-amd64.iso
